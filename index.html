01 / Quickstart

Start with the CLI. Move to the SDK when you need composition.

The CLI and SDK share the same canonical core, so behavior should not fork between shell workflows and application code.

terminal
bun add @solard/sdk
bun add -g solard-cli

slrd help
terminal
bun install
bun run ./packages/solard-cli/bin/solard.ts help
!
Live writes are explicit.

Many write paths are simulation/preview first. Commands that use the live-trading gate require SOLARD_ENABLE_LIVE_TRADES=1 plus the command's explicit live option.

02 / Design

Capability-oriented by design

Solard owns protocol access, deterministic transaction construction, wallet persistence, market data plumbing and execution boundaries. Strategy policy stays in scripts and applications.

01

One canonical core

@solard/sdk and slrd use the same implementation instead of duplicating trading logic.

02

Shared market data

One feed server fans prices out to watchers, agents and UI clients. A second strategy on the same mint does not create a second upstream subscription.

03

Bounded RPC pressure

JSON-RPC traffic is globally rate-limited to 5 req/s by default; live feed enrichment can reserve a smaller budget.

04

Explicit execution

Read, quote, simulate and build paths are separated from irreversible live actions wherever the command surface supports it.

03 / SDK

Build with @solard/sdk

The public SDK is the application-facing surface. Use the trader preset for wallet/trading workflows and the shared feed client for event-driven applications.

Core client

TypeScript
import { createTraderSolard, sol } from "@solard/sdk";

const slrd = createTraderSolard();

// list locally stored wallets
const wallets = slrd.listWallets();

// compose a native SOL transfer
const receipt = await slrd
  .tx("trader-1")
  .transferSol("RECIPIENT_ADDRESS", sol("0.01"))
  .send();

console.log(receipt.signature, receipt.status);

Shared price feed

Run one feed server, then subscribe from any number of SDK consumers. The SDK reference-counts listeners inside a process and reconnects/resubscribes automatically.

TypeScript
import { createPriceFeed } from "@solard/sdk";

const feed = await createPriceFeed({
  url: "ws://127.0.0.1:8788/ws",
  onStatus(event, data) {
    console.log(event, data ?? "");
  },
});

const stop = feed.watchPrice(mint, async (tick) => {
  console.log({
    priceSol: tick.priceSol,
    priceUsd: tick.priceUsd,
    marketCapUsd: tick.marketCapUsd,
    venue: tick.venue,
    at: new Date(tick.atMs),
  });
});

// later
stop();
feed.close();
MethodPurpose
watchPrice(mint, listener)Subscribe one consumer to one mint; returns an unsubscribe function.
watchPrices(mints, listener)Subscribe one callback to several mints.
watchLaunches(listener)Receive launch discovery events from the shared feed.
latest(mint)Read the newest price tick received by this SDK client.
close()Close the local feed client and clear listeners.
closedPromise that resolves when the client is fully closed.

04 / CLI

CLI reference

Search the common command surface. Use slrd help and command-specific help for the full current option set.

Wallets & assets

slrd wallet create trader-1Create an encrypted wallet.
slrd import <private_key> trader-2Import a signing wallet.
slrd wallets --tokens --token-totalsScan all stored wallets for SOL and token holdings.
slrd balances --wallet trader-1Show SOL + SPL balances for one wallet.
slrd transfer gxy1 --wallet owner --sol 1Transfer native SOL to a wallet/contact/address.
slrd unwrap-wsol --all-wallets --simulate-onlyPreview closing every owned WSOL account, including non-ATA accounts.
slrd reclaim inspect --all-walletsInspect Loader-v3 buffers/programs controlled by stored wallets.

Trading & consolidation

slrd quote buy <token> --sol 0.05Inspect a buy quote without submitting.
slrd buy <token> --wallet trader-1 --sol 0.05Buy through the configured route; simulation/live behavior depends on command flags.
slrd sell <token> --wallet trader-1 --bps 10000Sell a percentage of the wallet position.
slrd swap --from SOL --to <mint> --amount 0.1 --wallet trader-1Exact-input swap / quote flow.
slrd liquidate tokens --except <protected-token>Plan liquidation of unprotected supported tokens.
slrd sweep --to treasury --below 0.05Sweep low-SOL wallets to a destination.

Shared feed & strategies

slrd feed serve --rpc-rps 5 --rpc-read-rps 2Run one upstream Pump/PumpSwap/LaunchLab feed for all local clients.
slrd launch watch --venue pump,raydium-launchlab --min-mcap 5000 --ath-step-pct 20Consume the shared feed and notify on qualification/ATH policy.
slrd strategy run ./strategy.ts --token <mint> --wallet trader-1Run an onPrice strategy using the shared feed.
slrd strategy backtest ./strategy.ts --token <mint> --price-sample 5sReplay the same strategy file over historical data.

History & backtesting

slrd token backfill <mint>Index historical signatures without hydrating every transaction.
slrd token backfill <mint> --materialize --price-sample-ms 1000Build a sampled durable price tape.
slrd token backfill <mint> --exactHydrate exact fills when order-flow/volume research requires them.
slrd backtest <mint> --dip-pct 20 --profit-pct 40 --buy-sol 0.02Run the built-in ATH-drawdown/profit backtester.

Launchpads & Raydium

slrd launch pump --creator trader-1 --image ./token.png --description "…"Prepare/launch a Pump token with metadata.
slrd raydium quote --from SOL --to <mint> --amount 1Quote an exact-input Raydium route.
slrd raydium launchlab configsList available LaunchLab platform configurations.
slrd raydium launchlab buy <mint> --wallet trader-1 --amount 0.05Build/simulate or execute a LaunchLab buy.
slrd raydium cpmm create --wallet trader-1 --mint-a A --mint-b B --amount-a 1 --amount-b 1Create an arbitrary SPL/SPL CPMM pair.

Meteora DLMM

slrd meteora discover --timeframe 30m --sort fee-active-tvl --limit 20Discover DLMM pools using active-liquidity metrics.
slrd meteora candles <pool> --timeframe 5mFetch pool OHLCV data.
slrd meteora positions --wallet trader-1List a wallet's DLMM positions.
slrd meteora open <pool> --wallet trader-1 --sol 0.1 --bins 40 --strategy spotPrepare/open Spot liquidity.
slrd meteora move <position> --wallet trader-1 --bins 10Reposition an existing DLMM position.

05 / Architecture

One market feed. Many independent consumers.

Market data is shared; strategy state and signing remain isolated. This is the boundary that lets several agents or a future multi-user UI consume the same token feed without multiplying RPC subscriptions.

Same mint, multiple strategies.

The SDK reference-counts local listeners. Two strategies subscribing to the same mint still produce one logical upstream mint subscription/fallback path at the feed server.

06 / Environment

Runtime configuration

RPC_ENDPOINTPrimary Solana JSON-RPC endpoint.
HELIUS_RPC_URLOptional Helius endpoint used where configured.
SLRD_DB_PATHCanonical wallet/config database path.
SLRD_MASTER_KEYOptional non-interactive wallet encryption key.
SOLARD_ENABLE_LIVE_TRADES=1Master opt-in for live-write paths that use the live gate.
SLRD_RPC_MAX_RPSOverride the default global 5 req/s limiter only if the provider allows it.
SLRD_JUPITER_MAX_RPSJupiter fallback request budget.

Diagnostics

terminal
slrd <command> --measure
slrd <command> --measure-stream

--measure prints aggregate timings after the command. --measure-stream restores live measure-fn events for low-level debugging.
